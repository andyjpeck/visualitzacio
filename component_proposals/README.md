# Component Proposals (`component_proposals/`)

This directory contains architectural specifications and design documents for visualizer render components.

## Proposals

- **`duperscope.md`**: Specification for the Duperscope audio-reactive oscilloscope and geometric waveform mesh generator.
- **`frame_buffer.md`**: Architecture for ping-pong FrameBuffer textures and feedback loops.
- **`static_image.md`**: Integration specification for static image backgrounds, decals, and overlays.
