# Tracks Registry: Visualització

This registry tracks the planned, active, and completed workstreams across Visualització's 8-track roadmap.

---

## MVP Milestones: Foundation & Visual Studio (Tracks 1 – 4)

- [ ] **Track 1: Minimal Reactive Canvas & Audio Testbed**
  *Goal: Two-Plane architecture, Web Audio analyzer, live preview canvas, toggleable FPS overlay, and day-1 reactive audio visuals.*  
  *Link: [./tracks/track_1_reactive_canvas_audio_testbed/index.md](./tracks/track_1_reactive_canvas_audio_testbed/index.md)*

- [ ] **Track 2: Dynamic Expression Engine & Parameter Binding**
  *Goal: `expr-eval` sandboxing, real-time `$VARIABLE` bindings, `#FUNCTION(...)` library with `#BEAT_FRAMES` decay curves, and live formula test input.*  
  *Status: Planned (Spec & Plan to follow Track 1)*

- [ ] **Track 3: Modular Frame Buffer, Ping-Pong Feedback & Named Buffers**
  *Goal: Master Frame Buffer root lifecycle, dual-FBO ping-pong feedback motion trails, 6 GLSL blend modes, `@NAME` buffer pool, and Static Image component.*  
  *Status: Planned (Spec & Plan to follow Track 2)*

- [ ] **Track 4: Visual Studio Shell, Node Graph & Preset Import/Export**
  *Goal: Split-view UI, `@xyflow/react` node graph with auto-layout, universal `f(x)` inspector with inline autocomplete dropdown, and JSON preset serializer.*  
  *Status: Planned (Spec & Plan to follow Track 3)*
